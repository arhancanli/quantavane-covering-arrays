Construction: a Sherwood covering perfect hash family of strength 2, SCPHF(5; 32768, 8, 2): a 5 x 32,768 array of points of AG(1, 8), the elements of GF(8), each written as the vector (1, x) of GF(8)^2, the integer 8 + x. Its columns are the first 32,768 of the 8^5 = 32,768 5-tuples of GF(8) in lexicographic order, so any two columns differ in some row, and there their vectors (1, x) and (1, y) are independent. By the theorem of Sherwood, Martirosyan and Colbourn (2006) the family gives CA(5(8^2 - 8) + 8; 2, 32768, 8) = CA(288; 2, 32768, 8). The array is the classical 5-fold direct product of the orthogonal array OA(64; 8, 8, 2) of the affine plane (the affine functions u0 + u1 x on each row's points, the 8 constant rows shared).

Built from: nothing. There is no search and no ingredient array; the family is fixed by q = 8, n = 5 and k = 32,768.

Program: row r (r = 0, ..., 4) and column c (c = 0, ..., 32767) hold 8 + (floor(c / 8^(4 - r)) mod 8), the base-8 digits of c, most significant first. The file has two comment lines, then the 5 rows. For example, in Python 3: `q, n, k = 8, 5, 32768; print("\n".join(" ".join(str(q + c // q**(n - 1 - r) % q) for c in range(k)) for r in range(n)))` prints the 5 rows of this file. The field coding does not matter: any bijection of the 8 codes onto GF(8) keeps two different points different.

Checks before submission: two exact checks of the family by our own programs, written separately, each passing: every one of the C(32768, 2) pairs of columns tested row by row (C, checker/t2pairs.c), and the 32,768 column tuples found pairwise distinct (Python, checker/t2distinct.py), both in github.com/arhancanli/quantavane-covering-arrays with their logs in strength2/CA_288_2_32768_8. The expanded covering array was also checked directly (checker/t2expand.c), every pair of columns in two windows of 1,500 columns (the first and a random one) showing all 64 pairs of symbols. Red controls (a duplicated column, an entry not of the form (1, x), a one-digit change that makes two columns equal) fail both exact checks, and a duplicated column fails the window check.
